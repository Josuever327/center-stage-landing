# Center Stage 2026 · Landing

Landing del torneo Center Stage (Smash Club Paraguay) — 14 y 15 de noviembre, EON Play, Asunción.

```bash
npm install
npm run dev      # local
npm run build    # genera dist/
```

Publicar: `npm run deploy` (Cloudflare Pages, proyecto `centerstagepy`). Copia en GitHub Pages: `npm run deploy:github`.

Online: https://centerstagepy.pages.dev
