# Center Stage 2026 · Landing

Landing del torneo Center Stage (Smash Club Paraguay) — 14 y 15 de noviembre, EON Play, Asunción.

```bash
npm install
npm run dev      # local
npm run build    # genera dist/
```

Publicar en GitHub Pages: `npm run deploy` (compila y sube `dist/` a la rama `gh-pages`).

Online: https://josuever327.github.io/center-stage-landing/
